# Aplikasi Prediksi Skor Popularitas Lagu Spotify

Aplikasi web berbasis Streamlit yang memprediksi tingkat popularitas lagu (skala 0–100) menggunakan algoritma *Random Forest Regressor* berdasarkan atribut audio Spotify.

## Sumber & Lisensi Dataset
- **Nama Dataset:** Spotify-2000 (`Spotify-2000.csv`)
- **Sumber:** Kaggle - Spotify All Time Top 2000s Mega Dataset (1.994 lagu, 15 atribut)
- **Lisensi:** CC0: Public Domain / Open Dataset untuk keperluan edukasi
